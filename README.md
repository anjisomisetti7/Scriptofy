# Scriptofy
A Book Reading Platform
Scriptofy – Book Reading Platform UI/UX Design
📚 Project Overview
Scriptofy is a modern Book Reading Platform designed in Figma that allows users to easily explore, search, and download books from various categories.
The platform focuses on delivering a smooth, user-friendly, and visually engaging reading experience for book lovers.
The design emphasizes simple navigation, organized book categories, and an intuitive interface that helps users quickly discover their favorite books.

✨ Key Features


🔍 Easy Book Search


📖 Explore Multiple Book Categories


⬇️ Download Books for Reading


🧭 User-Friendly Navigation


🎨 Modern and Clean UI Design
